# Documentation Directory

This directory contains technical documentation for the YPF Backend project.

## File Naming Convention

All documentation files follow a standardized naming convention to maintain historical order and consistency:

### Format

```
NNNN_filename.md
```

Where:
- `NNNN` - 4-digit sequential number (0001, 0002, 0003, etc.)
- `filename` - descriptive name in kebab-case (lowercase with hyphens)
- `.md` - Markdown file extension

### Examples

- `0001_test-isolation-strategy.md`
- `0002_donor-unification-strategy.md`
- `0003_financial-transaction-api-research.md`

### Numbering

The numbering reflects the historical order in which documents were created. When adding new documentation:

1. Find the highest numbered file in the directory
2. Increment by one (e.g., if highest is 0004, use 0005)
3. Use kebab-case for the filename portion
4. Keep names descriptive but concise

### Purpose

This convention helps us:
- Track documentation chronologically for historical reference
- Maintain consistent file organization
- Make it easy to reference specific documents
- Avoid naming conflicts and ambiguity
